# Data

The datasets are not included in this repository. Place these files here before running the
classification and part-similarity code (all semicolon-separated):

| File | Contents |
|---|---|
| `table_1.csv` | Features, key column `ID` |
| `table_2.csv` | Features plus the binary target `Type`, key column `ID` |
| `Parts.csv` | Part catalogue: `ID`, `DESCRIPTION` and structured attributes |
